# 微信聊天归档查询

一个 Agent Skill，让 AI 编程代理在你本机的微信聊天归档里查找和研究：谁说过什么，某件事何时发生，最后怎么定的，文件和链接发在哪里，一个话题怎样演变。它也能跨多个会话、人物和时间段，把一件事、一个人或一段经历整理成有出处的报告。

## 能做什么

- **查事实**：一句话的问题直接回答，每条结论附原消息链接，在 Markdown 阅读器里点开即到。
- **做研究**：需要拼接多方信息的问题分五档：速览、标准、深入、彻查、穷尽，覆盖范围和用量逐档增加。
- **开始前一次问完**：档位、范围、附件读法等选择在花费之前一次问清，彻查和穷尽先给出估算；之后直到交付不再打断。
- **可读的报告**：速览以外的档位交付一份 `报告.md`，按问题必须回答的几个方面组织，写明结论、出处、覆盖范围和不确定之处。

## 隐私

- 只读，不修改归档里的任何文件。
- 检索在本机完成，技能本身不联网，不把聊天内容发给其他服务。
- 命中里的密码和密钥只指出位置，除非你要的正是它。

## 要求

- 支持 Agent Skills（`SKILL.md`）的代理，例如 Claude Code、Codex、Antigravity
- Python 3.11 或更高版本
- [ripgrep](https://github.com/BurntSushi/ripgrep)，`rg` 在 PATH 上
- 符合下文格式的微信聊天归档

## 安装

把 `wechat-archive` 目录整个复制到代理的技能目录，例如：

| 代理 | 位置 |
|---|---|
| Claude Code | `~/.claude/skills/wechat-archive` |
| Codex | `~/.codex/skills/wechat-archive` |
| Antigravity | `~/.gemini/config/skills/wechat-archive` |

请复制目录本身，部分代理不识别符号链接或目录联接。

第一次使用时，代理会问归档根目录在哪里，并记到技能目录的 `config.json`，格式见 `config.example.json`。环境变量 `WECHAT_ARCHIVE` 优先于它。

研究的报告和工作文件默认写在技能目录的 `outputs/<任务名>/` 下。其中含聊天内容，请勿提交到代码仓库。

## 使用

直接用自然语言问代理，例如问某人说过什么、某件事的经过、某段时间做过什么。研究类问题它会先列出要回答的几个方面和可选档位，你选定后它一直做到交付。

## 归档格式

- 每个会话一个目录，月度分卷是目录里的 `.md` 文件，附件和媒体放在会话目录下的其他子目录。
- 分卷开头：

  ```
  # 会话名 · YYYY-MM · NNN
  会话：<会话 ID>
  我：<本人 ID>
  群人数：<N>
  ```

  `· NNN` 是同月分卷序号；`我：` 和 `群人数：` 可省略，后者只用于群聊。
- 每条消息：

  ```
  <a id="msg-<全库唯一 ID>"></a>
  ### YYYY-MM-DD HH:MM:SS · 显示名 · 类型

  发送者：<ID> · 引用：msg-<被引用消息 ID> · 提到：<ID>,<ID>

  > 正文，每行以 "> " 开头

  - [附件名](相对路径)
    语音转写等附加说明，缩进两格
  ```

  时间为北京时间；`引用：` 和 `提到：` 可省略，`提到：notify@all` 表示 @所有人。正文先做 HTML 转义，再给 Markdown 特殊字符加反斜杠。
- 类型取值包括：文本、文件/链接/卡片、图片、动画表情、系统消息、视频、语音、位置。

## 命令行

代理通过 `wechat-archive/scripts/wxq.py` 检索，也可以手动运行：

```bash
python wechat-archive/scripts/wxq.py find 关键词 --chat 会话名 --from 2024-01
```

子命令：`find`、`count`、`digest`、`files`、`context`、`who`、`activity`、`chats`、`extract`、`link`，参数见 `wxq.py <子命令> -h`。
